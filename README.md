# [心AI] PS Nano Banana Bridge

Photoshop 和 Nano Banana / Comfly API 的桥接插件。
（感谢@TSUNE的技术支持）
## 核心功能

- 从 Photoshop 当前图层导出图片
- 发送到 Nano Banana API
- 接收生成结果
- 自动导入回 Photoshop
- 支持提示词模板管理
